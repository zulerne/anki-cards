# Front

Для чего нужен `errors.Join`?

# Back

`errors.Join` объединяет несколько ошибок в одну ошибку с цепочкой. Добавлен в
Go 1.20.

`errors.Is` и `errors.As` умеют искать совпадение внутри объединённой ошибки.
Это удобно, когда операция собирает несколько независимых ошибок, например
при закрытии нескольких ресурсов.
