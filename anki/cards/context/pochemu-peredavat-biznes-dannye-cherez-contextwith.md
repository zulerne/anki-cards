# Front

Почему не следует передавать обязательные бизнес-параметры через `context.WithValue`?

# Back

Нетипизированный key-value (`any` → `any`): нет проверки компилятором, легко ошибиться с ключом.

Неявная зависимость — из сигнатуры не видно что функция ожидает.

Усложняет тестирование.

`WithValue` предназначен для request-scoped данных, например request ID или
trace ID. Обязательные бизнес-данные лучше передавать явно через аргументы,
чтобы зависимость была видна в сигнатуре.
