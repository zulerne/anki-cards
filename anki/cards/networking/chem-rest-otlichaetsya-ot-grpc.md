# Front

Чем REST отличается от gRPC? Плюсы и минусы.

# Back

REST: HTTP + JSON, человекочитаемый, широкая поддержка, проще для публичных API. Минус: оверхед JSON, нет строгого контракта.

gRPC: HTTP/2 + Protobuf, строгий контракт (`.proto`), бинарный формат (быстрее), стриминг, кодогенерация. Минус: не читается напрямую, сложнее дебаг, нужна поддержка клиента.
