# Front

Какие HTTP-методы ты знаешь?

# Back

- GET — получить ресурс.
- POST — создать ресурс.
- PUT — заменить ресурс целиком.
- PATCH — частичное обновление.
- DELETE — удалить.
- HEAD — как GET, но без тела.
- OPTIONS — допустимые методы (CORS preflight).
