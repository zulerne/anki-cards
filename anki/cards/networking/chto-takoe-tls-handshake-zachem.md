# Back

Процесс установки шифрованного соединения:1) Client Hello — поддерживаемые шифры, случайное число.2) Server Hello — выбранный шифр + сертификат.3) Клиент проверяет сертификат, обмен ключами.4) Обе стороны вычисляют session key.Обеспечивает: шифрование (конфиденциальность), аутентификацию сервера, целостность данных.
