# Front

Как реализован `map` внутри Go?

# Back

До Go 1.24 (`hmap`): хеш-таблица с цепочками. Массив бакетов, каждый хранит до 8 пар ключ-значение. При коллизиях — overflow buckets (связный список). `tophash` (старшие 8 бит хеша) ускоряет поиск. Load factor > 6.5 — инкрементальная эвакуация с удвоением бакетов.

Go 1.24+ (Swiss Tables): открытая адресация. Group = 8 слотов + Control Word (8 байт статусов). Хэш делится: H1 (57 бит) — выбор группы, H2 (7 бит) — запись в Control Word. SIMD сравнивает H2 сразу с 8 слотами группы параллельно. Load factor 87.5%.

Рост через Extendable Hashing: таблица делится на две (Split), директория удваивается только при необходимости — копируются указатели, не данные.
