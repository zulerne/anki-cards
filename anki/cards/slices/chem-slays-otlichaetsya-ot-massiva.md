# Front

Чем слайс отличается от массива в Go?

# Back

Массив — фиксированный размер, передаётся по значению (копируется целиком). Слайс — дескриптор из 3 полей (ptr, len, cap), ссылается на базовый массив. При передаче в функцию копируется только дескриптор, не данные.
