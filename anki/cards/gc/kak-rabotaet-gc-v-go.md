# Front

Как работает GC в Go? (трёхцветная маркировка)

# Back

Concurrent mark-and-sweep с трёхцветной маркировкой:

- Белые — потенциально мусор.
- Серые — достижимые, но дети не проверены.
- Чёрные — достижимые, все дети проверены.

GC начинает с корней (стек, глобалы), красит серым, затем сканирует серых, перекрашивая в чёрные. Оставшиеся белые — мусор.

Write barrier сохраняет корректность при конкурентной работе.
