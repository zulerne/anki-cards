# Front

Что такое `GOGC`? Как он влияет на частоту сборки мусора?

# Back

Переменная окружения, задающая целевой рост heap между циклами GC. В расчёте
участвуют live heap и GC roots; это настройка компромисса CPU/память, а не
жёсткий таймер.

По умолчанию `GOGC=100` — GC запускается когда heap вырастает на 100% от размера после последней сборки.

`GOGC=50` — чаще (каждые +50%).

`GOGC=200` — реже (каждые +200%).

`GOGC=off` — отключить GC.

С Go 1.19+ есть мягкий лимит памяти `GOMEMLIMIT` (и
`runtime/debug.SetMemoryLimit`). В Go 1.26 стандартный runtime использует
Green Tea GC; это деталь реализации, а не гарантия спецификации.
