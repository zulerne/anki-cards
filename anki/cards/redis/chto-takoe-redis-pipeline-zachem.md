# Back

Отправка нескольких команд за один раунд-трип без ожидания ответа на каждую. Обычно: команда -> ответ -> команда -> ответ. Pipeline: команда, команда, команда -> ответ, ответ, ответ. Снижает latency в разы при массовых операциях.
