# Front

Чем строка отличается от []byte?

# Back

Строка — неизменяемый дескриптор (указатель + длина, 16 байт).[]byte — изменяемый слайс (указатель + длина + capacity, 24 байта).Конвертация []byte(s) / string(b) копирует данные (компилятор оптимизирует в ряде случаев).
