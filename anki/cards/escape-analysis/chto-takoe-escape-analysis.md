# Front

Что такое escape analysis?

# Back

Анализ компилятора, определяющий где аллоцировать переменную: на стеке или в куче.Если переменная «убегает» из функции (возвращается указатель, сохраняется в интерфейс, замыкание), она попадает в кучу. Стек дешевле: не нужен GC.Проверить: go build -gcflags="-m".
