# Front

Что такое пессимистическая vs оптимистическая блокировка?

# Back

Пессимистическая: блокирует запись при чтении (`SELECT ... FOR UPDATE`). Другие ждут. Гарантия — нет конфликтов, но снижает throughput.

Оптимистическая: не блокирует. При записи проверяет версию (`WHERE version = N`). Если версия изменилась — retry. Лучше при редких конфликтах.
