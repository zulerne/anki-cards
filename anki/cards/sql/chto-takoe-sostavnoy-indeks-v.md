# Front

Что такое составной индекс? В каком порядке важны столбцы?

# Back

Индекс по нескольким столбцам: `CREATE INDEX idx ON t(a, b, c)`.

Работает по принципу leftmost prefix — индекс используется для запросов по `(a)`, `(a,b)`, `(a,b,c)`, но НЕ по `(b)` или `(c)` отдельно.

Порядок столбцов: сначала столбцы для фильтрации (`WHERE`), затем для сортировки (`ORDER BY`).
