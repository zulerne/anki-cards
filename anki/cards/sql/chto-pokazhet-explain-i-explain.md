# Front

Что покажет EXPLAIN и EXPLAIN ANALYZE? Чем они отличаются?

# Back

EXPLAIN — план выполнения запроса БЕЗ его запуска (оценочная стоимость, ожидаемое число строк).EXPLAIN ANALYZE — выполняет запрос и показывает реальное время, реальное число строк, число итераций. ANALYZE нужен для сравнения оценки с фактом.
