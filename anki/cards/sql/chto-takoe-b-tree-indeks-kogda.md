# Front

Что такое B-tree индекс? Когда он помогает, когда нет?

# Back

Сбалансированное дерево поиска.Помогает: точный поиск (=), диапазоны (<, >, BETWEEN), сортировка (ORDER BY), поиск по префиксу (LIKE 'abc%').Не помогает: LIKE '%abc' (нет префикса), функции над столбцом (WHERE LOWER(name) = ...) — нужен функциональный индекс.Замедляет INSERT/UPDATE/DELETE (нужно обновлять дерево).
