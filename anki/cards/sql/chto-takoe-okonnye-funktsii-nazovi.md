# Back

Функции, вычисляемые по "окну" строк без группировки. Каждая строка сохраняется в результате.ROW_NUMBER() — уникальный номер строки.RANK() — ранг с пропусками при равенстве.DENSE_RANK() — ранг без пропусков.LAG(col, n) — значение из предыдущей строки.LEAD(col, n) — значение из следующей строки.Синтаксис: OVER (PARTITION BY ... ORDER BY ...).
