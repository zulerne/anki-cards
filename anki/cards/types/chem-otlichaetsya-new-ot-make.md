# Front

Чем отличается `new()` от `make()`? Для каких типов каждый?

# Back

`new(T)` — выделяет память под любой тип, заполняет нулями, возвращает `*T`.

`make(T, ...)` — только для `slice`, `map`, `channel`. Инициализирует внутренние структуры и возвращает сам `T` (не указатель).
