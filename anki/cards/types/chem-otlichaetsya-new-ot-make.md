# Front

Чем отличается `new()` от `make()`? Для каких типов каждый?

# Back

`new(T)` — создаёт новую нулевую переменную и возвращает `*T`. Начиная с Go
1.26, `new` также может принимать выражение и инициализировать указатель этим
значением, например `new(42)` имеет тип `*int` и значение `42`.

`make(T, ...)` — только для `slice`, `map`, `channel`. Инициализирует внутренние структуры и возвращает сам `T` (не указатель).
