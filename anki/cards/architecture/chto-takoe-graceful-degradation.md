# Front

Что такое graceful degradation?

# Back

Система продолжает работать с ограниченной функциональностью при отказе компонента.

Пример: кэш Redis упал — приложение читает из БД (медленнее, но работает). Сервис рекомендаций недоступен — показываем популярное. Лучше медленный ответ, чем ошибка.
