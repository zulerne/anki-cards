# Front

Какова сложность основных операций: массив, связный список, хеш-таблица, дерево?

# Back

Массив: доступ O(1), поиск O(n), вставка/удаление O(n).

Связный список: доступ O(n), вставка/удаление в начало O(1), поиск O(n).

Хеш-таблица: вставка/поиск/удаление O(1) в среднем, O(n) в худшем.

BST (сбалансированное): вставка/поиск/удаление O(log n).
