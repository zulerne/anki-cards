# Front

Что такое DFS и BFS? Когда использовать какой?

# Back

DFS (Depth-First Search) — вглубь (стек/рекурсия). Для: поиск пути, топологическая сортировка, обнаружение циклов.BFS (Breadth-First Search) — вширь (очередь). Для: кратчайший путь в невзвешенном графе, уровневый обход. DFS экономнее по памяти, BFS находит кратчайший путь.
