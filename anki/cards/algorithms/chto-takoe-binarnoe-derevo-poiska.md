# Back

BST: у каждого узла — левый потомок меньше, правый больше. Поиск: O(log n) для сбалансированного, O(n) для вырожденного (линейная цепочка). Сбалансированные варианты (AVL, Red-Black) гарантируют O(log n). Используется в map, set реализациях.
