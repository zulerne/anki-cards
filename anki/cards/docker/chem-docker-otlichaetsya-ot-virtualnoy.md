# Front

Чем Docker отличается от виртуальной машины?

# Back

VM: гипервизор + полная ОС + приложение. Тяжёлая (гигабайты), старт минуты, полная изоляция.

Docker: контейнер использует ядро хостовой ОС, изоляция через namespaces и cgroups. Лёгкий (мегабайты), старт секунды, меньше overhead. Не полная изоляция (общее ядро).
