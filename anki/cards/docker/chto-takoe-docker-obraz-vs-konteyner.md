# Front

Что такое Docker-образ vs контейнер?

# Back

Образ (image) — неизменяемый шаблон со слоями (файловая система + метаданные).

Контейнер — запущенный экземпляр образа с изолированным процессом, своей сетью и writable-слоем.

Аналогия: образ = класс, контейнер = объект.
