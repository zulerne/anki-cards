# Front

Что такое docker-compose? Для чего используется?

# Back

Инструмент для запуска многоконтейнерных приложений. Описание в docker-compose.yml: сервисы, сети, volumes. Одна команда docker compose up поднимает всё. Для локальной разработки: app + postgres + redis + kafka.
